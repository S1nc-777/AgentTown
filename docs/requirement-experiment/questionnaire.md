# AgentTown 内测验证问卷

> 目的：验证核心需求假设——**"异构多 Agent 协作（真实领导 Agent + 员工）是否比单 Agent 更好用"**。
> 发放对象：5-10 位 AI 编程重度用户（懂点技术但不多、日常使用 Codex/Claude Code/OpenCode 的人）。
> 配套材料：《内测操作指引》（experiment-guide.md）。

## 汇总方式

- 每份问卷回收后：按 Q1-4（背景画像）、Q5-9（关键证据）、Q10-12（定性反馈）归档。
- 关键判定标准：
  - **需求成立信号**：≥60% 受访者 Q8 选择"愿意多付少量及以上"，且 Q5 选择"明显更好用"，且 Q9 选择"会，马上想用"或"会，但等条件成熟"。
  - **需求不成立信号**：≥50% 受访者 Q5 选择"更难用/差不多"，或 Q8 选择"不愿意多付"。
  - 介于两者之间 → 转向信号：保留方向但换定位（如先做图形界面/真实 Agent 接入）。
- 汇总结果写入 `docs/requirement-experiment/findings.md`，决策写入 `decision.md`。
